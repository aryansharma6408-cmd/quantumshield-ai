AccuracyOverall fraction of correct predictions.

Macro-F1Unweighted average F1 across classes.

These metrics evaluate task-type classification only. They do not measure cryptographic security or PQC migration correctness.

PROJECT DOCUMENTATION

Research notes

Research framing and limitations carried forward from the supplied notebook.

01 / OBJECTIVE

LLM-assisted migration planning

Use an LLM as a reasoning and report-generation component, supported by evidence retrieval, transparent checks, testing, and human approval—not as a sole security oracle.

02 / CLASSICAL BASELINES

Text classification

Compare a majority baseline, TF-IDF + Logistic Regression, and TF-IDF + Linear SVM on candidate-only task-type labels.

03 / OPTIONAL MODEL

DistilBERT

The notebook includes an optional fine-tuned transformer experiment. Report its metrics only if that cell completes; this web app does not fabricate or infer transformer scores.

04 / VALIDATION

Independent verification

Build an independently reviewed test suite from primary standards and current library documentation. Add static checks, unit/integration tests, interoperability tests, performance tests, expert review and rollback planning.

Algorithm roles matter

ML-KEMKey establishment
ML-DSADigital signatures
SLH-DSADigital signatures

Key-establishment mechanisms and signature schemes are different cryptographic functions and must not be treated as interchangeable.

RESEARCH LIMITATIONS
  • Dataset metadata reports no verified records.
  • Quarantined PQC migration records are excluded from supervised target labels.
  • Candidate labels cover only classical hardening and non-PQC maintenance in this experiment.
  • Classification performance is not evidence of cryptographic correctness.
  • Pattern indicators are not a substitute for a cryptographic parser, static analysis, or expert review.
  • No automatic deployment is supported.
